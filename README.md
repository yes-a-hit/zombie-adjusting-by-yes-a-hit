# Zombie Fun Adjust · 妙趣横生的僵尸调整

> 面向 PvZ2 Gardendless 的僵尸体验调整 —— **削弱几个让人血压升高的机制，
> 让脉冲黄桃真正拦得住空中之城的飞机，并给几类僵尸补上它们本该有的特性。**

| | |
|---|---|
| 版本 | 1.2.6 |
| 适配 | PvZ2 Gardendless 0.15.0 + GP-Next 1.5.0-pre.1 |
| 前置 | 无（需要开启 JavaScript 模组） |
| uuid | `yg.zombie-fun-adjust` |

## 逐条说明

**1. 小鬼血量统一为 95**
18 只带独立血量的「小鬼」全部下调，含未来世界的机械虫小鬼。
小鬼炮是炮台装置、不在此列；节日系九只小鬼没有独立血量，会跟着普通小鬼一起变 95。
效果上：5 发豌豆一只。

**2. 重金属巨人**
舞台效果（Jam）期间**承受伤害减半**，同时**移除音波斩**。
做法是给 `extraDamageScale` 返回 `0.5`（与火龙小鬼免疫火焰是同一套机制），
并把 `onSmashing` 整体拦掉 —— 引擎里音波只在舞台效果期间射出，
所以拦掉它不会影响普通砸击。

**3. 脉冲黄桃瘫痪并强制落地所有飞机**
覆盖小鬼飞机、单体战斗机、双体战斗机、无人机、裁决者五类。
引擎里脉冲黄桃对范围内目标调用 `zombie.empStun()`，而**基类该方法是空函数** ——
全引擎只有 12 处覆写，飞行僵尸里仅有无人机有份，其余四类原本完全免疫。
现在五类全部补上覆盖，并借 `flying = false` 触发引擎的落地回调实现强制落地。
**僵王不在目标之列。**

**4. 像素僵尸每秒 10 点真实伤害**
直接改 `health`，**不经过任何减伤、免疫与防具判定** —— 无论带什么护具都会掉血。
本体、路障、铁桶三个变体一并生效。护甲会被同时削掉，血量归零后正常死亡。

**5. 雪人小鬼与宝藏雪人免疫冰系控制**
`iceage_imp`（雪人小鬼）与 `treasureyeti`（宝藏雪人）—— 即**所有类型的雪人僵尸**。
做法是把引擎的冰冻下发口 `Zombie.setFreeze()` 与减速下发口 `Zombie.setChill()`
对这两只拦掉，因此寒冰射手、冰冻类大招都冻不住它们。

> 说明：引擎的伤害类型（`ZombieDamageType`）里**没有「冰」**这个类别，
> 所以做不到像火龙小鬼免疫火焰那样按伤害类型免疫，只能拦状态。

**6. 蜻蜓 / 萤火虫护甲削到 90**
蜻蜓僵尸（`lostcity_bug`）背上驮着一只蜻蜓当**护甲**，引擎里这只蜻蜓的血量叫
`BugToughness`，原本是 **350** —— 比僵尸本体（190）还厚。
现在连同三个变体（路障 / 铁桶 / 帐篷头）与仲夏夜的萤火虫换皮版本
（`summer_bug` 系列）一起削到 **90**。

**7. 魔音甜菜不再被朋克僵尸踢飞**
引擎里 `EightiesPunkZombie.whenPlantDetected` 会先检查所在行有无植物带
`CannotBePushedByFootballMech` —— 有则改为正常吃植物，不再推走。
白萝卜（`turnip`）免踢飞靠的就是这个字段，给 `phatbeet` 与 `phatbeet_rhythm`
一并加上即可，纯数据补丁。

**8. 国王 / 亚瑟王 —— 出场期间不再无敌**

引擎里国王的免打**不是** `invincible`，而是一套「假命中框」：

```js
setBodyRec(t) {                       // 基类：周期性重算命中框
  t || this.currentFarBodyRec() || this.bodyRecHiddenCD > 0
    ? this.bodyRec = new Rect()       // 空矩形
    : this.defaultSetBodyRec()
}
```

国王出场整段 `switching = true`，于是 `bodyRec` 被反复置空 —— 有血条却打不到。
本模组挂在 `Zombie.prototype.setBodyRec` 上，出场期间强制走正常路径
（**只拦这一层，不写回 `switching`**，避免打断随后的授爵流程）。

同时把血量上限与当前血量一起压低：

| | 出场期间 | 落地后 |
|---|---|---|
| 杖国王 `dark_king` | **200** | 回满 **1000** |
| 剑国王 `dark_king_veteran` | **300** | 回满 **1500** |

「落地」的判定用 `switching` 转 `false` 这个信号 —— 国王是 `GridZombie`，
出场播的是 `playAnimation("Spawn")`，**不走 `playDirtSpawn`**，
所以 `onDirtSpawned` 那条路根本不会触发。

**9. 国王 / 亚瑟王 —— 授爵自扣血**

`DarkKingZombie._give()` 就是「给僵尸授爵」那趟流程：随机挑相邻一行，
再挑一只通过 `zombieCanAddArmor` 的僵尸，把护甲挂上去。
挂上它，每次调用扣自己 **150** 血。国王（1000 血）与亚瑟王（1500 血）都生效。

**10. 街机游戏机**
召唤池只剩「像素僵尸 / 像素路障」，不再出像素铁桶；
每召唤出一只，机器自身扣 **100** 血。

**11. 轮滑（闪耀）僵尸**
踩到地刺直接死亡，地刺本身不掉血——和引擎里钢琴、滚桶那类载具僵尸同一套写法。

**12. 霹雳舞僵尸**
原本一次能把 1.5 格内的僵尸**全部**踢飞。现在只踢一只；
踢中之后自己扣 **50** 血（空踢不扣）。

**13. 麦克说唱家**
甩完麦克风后自杀。**攻击伤害照常结算**，只是甩完自己倒下。

**14. 章鱼僵尸**
每扔一次章鱼自扣 **150** 血。

**15. 弄臣**
旋转期间持续掉血，每秒 **20** 点。按 420 点血算，大约转十次就会自己倒下。

## 快速开始

1. 游戏内按 `F12`，在 Console 执行一次 `await gpNext.mods.enableJsModding()`
2. 取得安装包 ZIP —— 在 **Releases** 页面下载，或克隆本仓库后运行 `npm run pack` 自行打包
3. GP-Next 侧栏 → **模组** → **导入 ZIP**，选中上一步得到的 zip
4. **在模组列表里把它勾上**（导入后默认不勾，**不勾等于没装**）
5. 点 **保存并应用**，按提示重启游戏

**不需要任何额外脚本、命令行或补丁工具。**

> **第 4 步最容易漏。** 包导入后在 `installed/` 和配置里都在，但 `enabled` 是 `false`，
> 此时 JS 一行不跑、数值补丁一条不生效，表现就像"没装"。

遇到问题见 [`docs/INSTALL.md`](docs/INSTALL.md)（含一份常见故障排查表）。

## 生效确认

装好后可以这样快速验证：

- **小鬼**：5 发豌豆一只
- **重金属巨人**：舞台效果期间不再有音波，且血掉得明显慢
- **脉冲黄桃**：放到飞机下方引爆，飞机会当场落地；无人机直接坠毁
- **像素僵尸**：血条持续下滑，路障 / 铁桶护具也挡不住
- **雪人小鬼 / 宝藏雪人**：寒冰射手打上去不减速、不冰冻
- **蜻蜓僵尸**：背上的蜻蜓一碰就掉
- **魔音甜菜**：朋克僵尸遇到它只会吃，不会把它踢飞
- **街机**：只召唤像素僵尸 / 像素路障，且每次召唤机器自己掉血
- **轮滑**：踩地刺直接死
- **霹雳舞**：一次只踢一只，踢完自己掉 50
- **RAP**：甩完麦自己倒下
- **章鱼**：扔一次掉 150
- **弄臣**：开始旋转后血条持续下滑

日志里搜 `僵尸调整`，能看到依赖解析结果与各条钩子的挂载状态。

## 项目结构

仓库根**同时就是模组根** —— `pack.json` 在最顶层，所以 `git clone` 之后可以直接用
GP-Next 的「导入文件夹」选中仓库根，不需要额外构建步骤。

```
zombie-fun-adjust/
├── pack.json              GP-Next 模组清单
├── jsons/objects/         数据补丁：小鬼血量、蜻蜓护甲、魔音甜菜
├── scripts/main.js        运行期入口：13 条行为钩子（ESM）
├── tests/                 模拟验收测试（不需要游戏本体）
├── tools/pack.ps1         发布打包：白名单 + 校验 + 用产物复测
├── docs/
│   ├── INSTALL.md         安装、部署与排查
│   └── ENGINE-NOTES.md    引擎笔记：每条改动挂在哪、为什么
├── package.json           仅开发用（`type: module` + npm scripts）
├── LICENSE                MIT 全文
├── NOTICE.md              非代码内容的来源与归属
└── CHANGELOG.md
```

发布的 ZIP **只含运行时文件**
（`pack.json` + `README.md` + `LICENSE` + `NOTICE.md` + `jsons/` + `scripts/`），
`tests/`、`tools/`、`docs/`、`package.json` 等开发用文件不会进包。

`LICENSE` 与 `NOTICE.md` 进包不是可选项：MIT 条款要求版权声明与许可声明
随软件的所有副本分发。

## 开发

需要 Node.js（跑测试）。打包需要 Windows PowerShell。

```bash
npm test        # 跑模拟验收测试
npm run pack    # 生成 dist/*.zip，并自动用打包产物复测一遍
```

打包脚本做四件事：白名单暂存 → 正斜杠 ZIP → 校验条目与清单字段 → 解包并用包里的
`scripts/main.js` 重跑同一套断言。等价的手动复测：

```bash
JBTMG_PKG_ROOT=<解包目录> JBTMG_ENTRY=<解包目录>/scripts/main.js node tests/run.mjs
```

测试细节见 [`tests/README.md`](tests/README.md)，每条改动的引擎依据见
[`docs/ENGINE-NOTES.md`](docs/ENGINE-NOTES.md)。

## 已知限制

- **冰系免疫只作用于冰冻与减速，不含伤害**。引擎的伤害类型里没有「冰」这一类别
  （`ZombieDamageType` 只有 `physicle` / `fire` / `electricity` / `potatoMine` / `ray`），
  寒冰射手的豌豆在引擎看来与普通豌豆同类，**无法按伤害类型区分**。
- **像素僵尸的真实伤害同样不区分来源** —— 它是直接改本体血量，
  因此任何来源的 10 点都会结算。
- **数值补丁需要重启生效**；运行期钩子只影响运行时新建或更新的实例。
- 若某个类在未来版本改了方法名，对应那条会挂载失败，
  日志与面板会明确写出是哪一个。

## 开发方式声明

本模组的引擎逆向、机制定位与代码实现，由 **DSH（DeepSeek Harness）** 与
**DeepSeek V4.1f** 协作完成。

具体分工与可核对的产物：

- **机制逆向** —— 在约 3.75 MB 的引擎副本（`docs/assets/main/index.js`）上按类定位，
  用 `grep` 找调用点、再提取整类读实现。每条改动都先确认**挂在哪一层**才动手。
  例如：国王的「无敌」并非 `invincible`，而是基类 `setBodyRec` 周期性把 `bodyRec`
  置成空矩形；而其「落地」信号是 `switching` 转 `false`（它不走 `playDirtSpawn`）。
- **代码实现** —— 运行期 JS 钩子（20 条挂载）、数据补丁（`jsons/objects/*.json`）、
  打包脚本与 **163 项模拟验收测试**。
- **交叉验证** —— 改动前先在引擎里找到对应的实现依据，改动后跑测试、
  并用打包产物再复测一遍（160 项）。
- **失败记录** —— 走过的弯路（含放弃的功能与原因）完整保留在 `CHANGELOG.md` 里，
  不掩盖、不删除。

> 说明：数值平衡与「删什么、留什么」的取舍由模组作者决定；
> 上列协作产出的是**机制定位、实现与验证**。
